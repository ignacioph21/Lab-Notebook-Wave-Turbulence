\subsection*{Generar señal analógica de ruido.} 
Una de las partes importantes va a ser generar una señal analógica entre 0 y 10 V de ruido limitado en banda de frecuencia, ya sea en tiempo real, o de una longitud suficientemente larga como para que no se llegue a repetir nunca.

Para esto mi primera idea fue usar directamente un Arduino, sin embargo, no cuentan con una salida analógica, solo con salidas digitales tipo PWD. 


Podríamos pensar en usar la función de ruido del generador de funciones pero tiene varias complicaciones. El ruido del generador es ruido blanco (no limitado en frecuencia), con lo cual habría que poner un filtro-pasabajos analógico que nos sacaría mucha amplitud (con lo cual habría que poner un amplificador) y sería muy poco flexible. Además no podríamos asegurarnos fácilmente que la corriente de ese circuito sea del orden de 1-5 mA que es lo que pide el motor. 

La única alternativa que quedaba era volver a intentar usar la DAQ como generador de una señal analógica. Inicialmente no había podido configurarla para que use las señales pre-configuradas en frecuencias altas, pero sí para que ponga un VDC como output en alguno de los canales. Lo que pensé entonces fue que como las frecuencias de nuestras señales son relativamente bajas podemos ir actualizando ese VDC constantemente para formar la señal que querramos (notemos que esto está limitado por la velocidad de ejecución de cada iteración del código que implica una comunicación completa entre la computadora y la DAQ con lo cual no funcionaría para generar la señal sinusoidal de 50 kHz para el RLC). 

El código para manejar la placa terminó siendo el siguiente: 


\begin{lstlisting}
import numpy as np
import time
from scipy.interpolate import interp1d
from PyIOTech.daq import daqDevice
from PyIOTech.daqh import DddtLocal

fs = 100              
duracion = 3600       
fmin, fmax = 0, 4    
amplitud = 3.0

N = int(fs * duracion)
tiempos = np.arange(N) / fs

freqs = np.fft.rfftfreq(N, 1/fs)
espectro = np.zeros(len(freqs), dtype=complex)
indices = np.where((freqs >= fmin) & (freqs <= fmax))[0]
espectro[indices] = np.exp(1j * 2 * np.pi * np.random.rand(len(indices)))

senal = np.fft.irfft(espectro)
senal *= amplitud / np.max(np.abs(senal))

interpolador = interp1d(tiempos, senal, kind='linear', fill_value='extrapolate')


dev = daqDevice(device_name)
t_prev = time.perf_counter()
t_actual = 0.0  

while t_actual < duracion:
	t_now = time.perf_counter()
	dt_actual = t_now - t_prev
	t_actual += dt_actual
	t_prev = t_now	
	
	v = float(interpolador(t_actual))
	dev.DacWt(deviceType, channel, v)
finally:
	dev.DacWt(deviceType, channel, 0.0)
	dev.Close()

\end{lstlisting}


Este código genera una señal muy larga y la va evaluando en los tiempos que la placa le pregunta a la computadora el siguiente voltaje, mediante interpolación (aunque al generar la señal con una frecuencia de muestreo muy alta esto no debería introducir error). Probé generar la señal en tiempo real pasando ruido blanco por un filtro pasabajos exponencial pero no terminaba de limitar bien la banda de frecuencias y quedaba muy ruidosa la señal. 

En el osciloscopio verifiqué que seguro hasta 17 Hz funciona bien este método para generar senos, y seguro más frecuencia también. Después verifiqué que el ruido se veía razonable. Por ultimo levanté con la otra DAQ la señal para verificar que esté bien limitada y de fase aleatoria y así resultó.
